# UI Standards & Design System — Cryo Scientific ERP

## Visual Identity
- **Company**: Cryo Scientific Systems Pvt. Ltd.
- **Brand Aesthetic**: Modern, clean, business ERP interface for medical and industrial scientific refrigeration.
- **Primary Color Palette**:
  - Brand Navy: `#0f2d59` (`brand-900`)
  - Corporate Accent: `#2a66a3` (`brand-600`) / Sky `#38bdf8`
  - Success / Active: `#059669` (Emerald 600)
  - Warning / In Progress: `#d97706` (Amber 600)
  - Danger / Loss / Mismatch: `#dc2626` (Rose 600)
  - Neutral Background: `#f8fafc` (Slate 50) and `#ffffff` (White)
  - Neutral Borders: `#e2e8f0` (Slate 200)

## Typography & Hierarchy
- **Font Family**: Inter, system-ui, -apple-system, sans-serif
- **Page Titles**: `text-xl font-bold text-slate-900`
- **Section Headers**: `text-xs font-bold uppercase tracking-wider text-slate-700`
- **Table Data**: `text-xs text-slate-800`
- **Document Numbers**: `font-bold text-brand-900 font-mono`

## Form & Dialog Standards
- All inputs styled with subtle border `border-slate-200`, background `bg-slate-50`, focus ring `focus:border-brand-600`.
- All modals provide accessible backdrop dismiss, escape key handler, and clear Cancel/Confirm actions.
- Touch-friendly sizing on buttons and tap targets for tablet and mobile viewports.
