# Project: Cryo Scientific Systems – Sales Workflow Management System

## System Purpose
Enterprise Sales Workflow Management System specifically designed for Cryo Scientific Systems Pvt Ltd to govern the complete commercial process from initial inquiry/lead through quotation revision cycles, customer PO verification, and formal sales order handover to production.

## Technology Stack
- **Backend**: Node.js + Express.js (CommonJS), MongoDB, Mongoose, JWT, bcryptjs, Multer, PDFKit.
- **Frontend**: Vite + React.js (.jsx), Tailwind CSS, Lucide React, Zustand, Axios, React Router v6, Day.js.
- **Port Allocations**:
  - Backend: `http://localhost:5000`
  - Frontend: `http://localhost:5173`
  - MongoDB: `mongodb://127.0.0.1:27017/cryo_sales_db`

## Current Development Phase
- Phase 1: Backend Foundation (Models, Controllers, Auth, Multer, PDFKit, Seeds)
- Phase 2: Frontend Foundation (Vite, Tailwind, Navigation, Layout, Auth Store)
- Phase 3: Complete 12-Stage Sales Workflow
- Phase 4: Dashboard, Timeline, Verification & Testing
